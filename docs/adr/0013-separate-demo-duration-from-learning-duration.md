# Separate Demo Duration from Learning Duration

The 2–3 minute promise will describe a focused Demo Slice, not the complete learning path. Demo Mode should take roughly 60–90 seconds, while Start Learning may take around 4–5 minutes to include the tutorial, active Red practice, and Transfer Check without compressing the coaching.

This resolves the time conflict created by adding safety practice and transfer evidence while keeping the hackathon experience quick to understand.
