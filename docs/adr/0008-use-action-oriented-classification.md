# Use Action-Oriented Classification

Signal classification will be judged by the practical action supported by the available evidence, not by whether the player guessed the speaker's private intention. Ambiguous workplace communication can have several possible motives; the learning target is choosing a useful next step such as clarifying, pausing, or responding lightly.

This keeps the game honest about uncertainty and makes its feedback transferable without teaching players that social interactions have one reliably knowable hidden meaning.
