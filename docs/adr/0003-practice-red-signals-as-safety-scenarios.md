# Practice Red Lights as Safety Scenarios

Red Lights will be practised in an active gameplay scenario rather than taught only in the tutorial. The scenario will teach pausing, de-escalation, and appropriate support-seeking so the game does not imply that successful workplace adaptation means automatic compliance.

**Considered Options**

- Teach Red only in the tutorial.
- Add a Red scenario as part of the active gameplay or Transfer Check. **Chosen.**

**Consequences**

The content must distinguish ordinary workplace ambiguity from situations requiring a boundary or support, and the safety guidance should be reviewed with the charity partner or a qualified practitioner before public release.
