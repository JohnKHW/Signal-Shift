# Separate Opt-In Measurement Mode

Ordinary gameplay will remain session-only and will not collect identifiable or cross-session records. A future Measurement Mode may record pseudonymous session data for treatment or research evaluation only after explicit opt-in, with appropriate consent, governance, and a separate validated pre/post measure; Game Impact Data must not be presented as clinical evidence.

This keeps the MVP privacy-preserving while creating a deliberate path for future longitudinal evaluation instead of silently turning a game into a treatment-monitoring system.
